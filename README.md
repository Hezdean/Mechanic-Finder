🚗 Automotive Repair Bidding Platform Featuring AI Assistant

📌 Overview

The Automotive Repair Bidding Platform Featuring AI Assistant is a web-based system that connects vehicle owners with freelance mechanics through a transparent bidding process enhanced by artificial intelligence. Customers can post service requests, mechanics can submit bids, and administrators manage system operations. The platform improves trust, efficiency, and accessibility in automotive repair services.


---

🎯 Objectives

Enable customers to post vehicle repair requests.

Allow mechanics to bid competitively on jobs.

Provide AI-assisted vehicle diagnostics.

Verify mechanic profiles using AI image verification.

Support secure authentication and payments.

Improve transparency and service quality.



---

🧩 Key Features

User roles: Customer, Mechanic, Administrator

Job posting and bidding system

AI diagnostics assistant

AI image verification for mechanic credentials

Chat system for communication

GPS location support

Mobile money payment integration

Review and rating system



---

🛠️ Technologies Used

Frontend: React.js, HTML, CSS, JavaScript

Backend: Node.js, Express.js (REST API)

Database: PostgreSQL

AI Services: AI diagnostics & image verification

External APIs: GPS/Maps, Mobile Money, Notifications



---

🏗️ System Architecture

The system follows a layered architecture:

Presentation Layer (React Frontend)

Application Layer (Node.js Backend)

Data Layer (PostgreSQL Database)

AI & External Services Layer
